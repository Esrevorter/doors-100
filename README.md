# 🚪 ONE HUNDRED DOORS

**100 hand-crafted HTML pages. Zero repetitive designs.** Every file ships with its own theme, palette, typography, layout, and interactive gimmick — no shared CSS, no template reuse, each page a self-contained single file (inline CSS + vanilla JS).

🔗 **Live gallery:** https://Esrevorter.github.io/doors-100/pages/index.html

## What's inside

| Range | Flavour |
|-------|---------|
| 001–020 | Immersive canvas worlds: starfields, synthwave grids, particle poetry, deep-sea descent |
| 021–045 | Interactive toys: draw-a-waveform synth, emoji orchestra, pixel studio, tarot deck |
| 046–070 | Design movements done authentically: brutalism, art deco, glassmorphism, glitchcore, Geocities 1999 |
| 071–090 | Editorial & data: broadsheet newspaper, type specimen, mission control, Game of Life |
| 091–100 | Scenes & oddities: night bus in the rain, jazz cellar, elevator panel, constellation maker |

All 100 pages are linked from `pages/index.html` — start there.

## Run locally

```bash
git clone https://github.com/Esrevorter/doors-100.git
open doors-100/pages/index.html   # or just serve it:
python3 -m http.server -d doors-100 8000
```

No build step, no dependencies, no internet required (Google Fonts degrade gracefully to system stacks).

## Repo layout

```
pages/        ← 100 numbered pages + index.html gallery hub
generate.py   ← generator used during development
```
